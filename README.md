# NewNote

Локальное приложение для заметок под Windows со свободным холстом, рукописным вводом и полной поддержкой графических планшетов. Написано на Rust (egui/eframe, OpenGL). Все данные хранятся только на вашем компьютере: без облака, учётной записи и телеметрии.

## Сборка

```bash
cargo build --release
```

Готовый файл: `target/release/newnote.exe`.

## Возможности

**Структура.** Блокноты → группы разделов (с вложенностью) → цветные разделы (16 цветов) → страницы и подстраницы (2 уровня). Создание, переименование, дублирование, перемещение (в том числе перетаскиванием страницы на раздел и между блокнотами), объединение разделов, закрепление страниц, сворачивание подстраниц, сортировка. Корзина со сроком хранения, шаблоны (встроенные и свои), шаблон по умолчанию для раздела.

**Хранение.** Блокнот — открытая папка: `notebook.json`, `pages/*.page` (JSON или AES-256-GCM), `assets/`, `versions/`. Автосохранение в фоновом потоке, атомарная запись, резервные копии по расписанию (с шифрованием), восстановление одним действием, проверка целостности с восстановлением потерянных страниц, размер блокнота. Экспорт и импорт архива `.nnbz`, объединение блокнотов с выбором версии при конфликте.

**Графический планшет.** Перо читается напрямую из Windows Ink (`WM_POINTER`, `GetPointerPenInfoHistory`): все промежуточные отсчёты с собственным нажимом, субпиксельная точность, обратный конец пера — ластик, боковая кнопка — лассо, курсор при наведении. Отключены задержки «нажать и удерживать» и жесты Windows. Раздельные режимы: перо, палец, мышь. Сглаживание и кривая нажима настраиваются; в параметрах есть проверка нажима.

**Рисование.** Перья и маркеры (цвет, толщина, прозрачность, наборы и избранное), ластик по штрихам и по точкам, лассо с перемещением, поворотом, масштабированием, копированием, линейка с привязкой и транспортир, фигуры (линия, стрелка, прямоугольник, овал, треугольник, звезда, выноска) с заливкой, автовыравнивание нарисованных от руки фигур. Фоны: чистый, линейка, клетка, точки, миллиметровка; безграничный холст или A4/A5/Letter; цвет страницы; масштаб колесом и щипком.

**Производительность.** Штрихи тесселируются один раз и кэшируются, на экран выводятся только видимые; при панорамировании и масштабе меши лишь пересчитываются. Точки прореживаются алгоритмом Рамера–Дугласа–Пекера, при отрисовке сглаживаются сплайном Катмулла–Рома. Изображения декодируются в фоне, сохранение страниц и индексация идут в отдельных потоках, отмена хранит снимки с общими буферами точек (до 100 шагов).

**Текст.** Шрифт, размер, цвет, выделение цветом, жирный, курсив, подчёркивание, зачёркивание, индексы, очистка и формат по образцу; выравнивание, отступы, интервалы, направление текста; стили (заголовки 1–6, цитата, код, примечание); маркированные, нумерованные, многоуровневые списки и чек-листы с автоформатом; проверка орфографии словарями Windows с подсказками и пользовательским словарём; автозамена; поиск и замена; распознавание ссылок, почты, телефонов и дат.

**Теги и задачи.** Встроенные и свои теги (значок, цвет, `Ctrl+1…9`), задачи со сроком и приоритетом, сводка тегов с фильтрами и вставкой на страницу, «Мои задачи», системные уведомления о сроках.

**Таблицы.** Строки и столбцы, объединение и разделение ячеек, ширина и высота перетаскиванием, автоподбор, заливка, границы, выравнивание, сортировка, заголовок и чередование строк, формулы (`SUM`, `AVERAGE`, `MIN`, `MAX`, `COUNT`, арифметика и ссылки на ячейки), CSV и XLSX, преобразование текста в таблицу и обратно.

**Вставка.** Изображения (файл, буфер, перетаскивание; обрезка, поворот, отражение, размер, подпись, замещающий текст, сжатие), снимок экрана, файлы-вложения, печатная копия PDF, аудио и видео как вложения, ссылки на сайты, файлы, страницы, разделы, блокноты и абзацы, формулы с решением уравнений и графиками, дата и время, символы и эмодзи, разделители, блоки кода с подсветкой, ментальные карты и блок-схемы.

**Распознавание (на устройстве).** OCR изображений и рукописи через Windows.Media.Ocr: копирование, поиск по распознанному тексту, замена рукописи текстом, преобразование в формулу или таблицу.

**Поиск.** Фоновый индекс по тексту, заголовкам, тегам, рукописи и тексту на картинках; области поиска, фильтры по дате, тегу, автору и типу, недавние и сохранённые поиски, подсветка на странице.

**Умный помощник (локально).** Сводка страницы и раздела, задачи и сроки из текста, исправление и упрощение текста, планы по теме, ответы на вопросы по заметкам, предложения тегов и заголовков, карточки для повторения.

**Чтение.** Чтение вслух голосами Windows с подсветкой слова, скорость, громкость, крупный шрифт, интервалы, фокус на строке, слоги; голосовой ввод Windows (`Win+H`); режимы фокусировки (`F11`) и презентации (`F5`).

**Совместная работа без облака.** Блокнот в общей сетевой папке: блокировка страницы на время редактирования и предупреждение о занятой странице, автор изменений, комментарии с упоминаниями.

**История.** Версии по таймеру и при закрытии, сравнение с подсветкой различий, восстановление целиком или по блокам, настраиваемые сроки.

**Защита.** Пароль на раздел или блокнот (AES-256-GCM, ключ Argon2id), блокировка по бездействию и `Ctrl+Alt+L`, шифрование резервных копий, метки конфиденциальности, запрет копирования и печати, очистка временных файлов.

**Экспорт и печать.** PDF, DOCX, HTML, Markdown, TXT, PNG, JPG, CSV, XLSX, архив блокнота. Печать с ориентацией, полями, масштабом, заголовком и нумерацией.

**Система.** Быстрая заметка `Win+Alt+N` из любого места, пункт «Добавить файл в блокнот» в проводнике, перетаскивание файлов, отдельные окна страниц и окно поверх других, автозапуск, тёмная, светлая и системная тема, режим для сенсорных экранов.

## Ограничения

- Нет виртуального принтера: документ из другой программы можно напечатать в PDF и вставить как печатную копию.
- Запись аудио и видео с микрофона и камеры не встроена; файлы вставляются как вложения.
- Перевод текста и распознавание частей речи не реализованы: для них нет локальных языковых моделей.
- Голосовой ввод использует системный набор текста Windows.
- Формат PDF при экспорте растровый (текст не выделяется).
